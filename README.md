# 💰 Rastreador de Despesas & Fluxo de Caixa

Sistema de controle financeiro pessoal desenvolvido de forma incremental, evoluindo de uma aplicação de linha de comando (CLI) em Python para uma arquitetura Full-Stack com banco de dados relacional PostgreSQL e interface Web.

---

## 🚀 Funcionalidades Atuais (v1.0 - MVP)

- **Cadastro de Despesas:** Registro rápido com formatação automática de texto.
- **Listagem Numerada:** Exibição limpa dos itens cadastrados em memória.
- **Arquitetura Modular:** Separação entre camada de interface (`main.py`) e regras de negócio (`gerenciador.py`).

---

## 🗺️ Roadmap de Evolução

- [x] **v1.0 (MVP):** CLI básico em Python com armazenamento em memória.
- [ ] **v2.0 (Fluxo de Caixa):** Entradas e saídas, data automática (`DD/MM/AAAA`), cálculo de saldo, extrato cronológico, persistência em JSON e exportação para `.csv`.
- [ ] **v3.0 (Banco de Dados SQL):** Migração para banco relacional **PostgreSQL** utilizando o padrão Repository.
- [ ] **v3.1 (Relatórios Avançados):** Filtros SQL por mês/ano, categoria e intervalo de datas.
- [ ] **v4.0 (Full-Stack Web):** API REST em **Node.js (Express)** integrada a um dashboard visual em **HTML5, CSS3 e JavaScript**.
